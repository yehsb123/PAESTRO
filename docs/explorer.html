멀티스텝 오케스트레이션

한 문장의 복합 요청을 단계로 쪼개, 각 단계를 엔진에서 검색해 크로스-런타임 실행 계획을 짠다. 위험 단계는 실행 전 승인.

>

python demo/orchestrate.py "…" — 규칙 기반 분해 스파이크(살아있는 엔진 검색). 실제 제품은 LLM planner + Verify 루프.

어떻게 쓰나

통합 CLI pae.py 하나로 크롤부터 검색·색인까지. VS Code 확장에선 이 검색이 번호 후보 UI로 뜬다.

# GitHub 오픈소스 크롤 → 레지스트리(996 capability) python pae.py crawl # 자연어로 도구 검색 (한국어 OK) → 번호 후보 python pae.py search "체리픽 커밋" # 레지스트리 통계 · 위험(승인 대상) 집계 python pae.py stats --risky # 엔진에 색인 → 실시간 의미 검색 python pae.py index --post http://127.0.0.1:8756
